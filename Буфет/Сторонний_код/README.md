# Сторонний код

Файлы в этой папке **не являются частью расширения «Буфет»** и никуда
не вставляются. Они лежат здесь как справочный материал.

## форма_отчета.bsl

Образец модуля формы отчёта на СКД: работа с настройками компоновки,
пользовательскими полями, отборами и оформлением.

| | |
|---|---|
| Лицензия | Attribution 4.0 International (CC BY 4.0) |
| Правообладатель | указан в шапке файла, 2020 |
| Объём | ~1900 строк, 77 процедур и функций |

**Условие лицензии CC BY 4.0** — при использовании кода в своём решении
нужно сохранить указание авторства из шапки файла.

Зачем хранится: как рабочий пример того, как устроена типовая форма отчёта
на СКД. Пригодится при создании `Отчет.АнализСебестоимостиСДиаграммой`
(см. раздел инструкции «Что нужно доработать»).

Если образец не нужен — папку можно удалить целиком, на работу расширения
это не влияет. Файл останется в истории git.
