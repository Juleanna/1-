## Буфет

Кулинарная подсистема: от технологической карты до списания сырья и анализа себестоимости.

Папка [Буфет/bufet/](Буфет/bufet/) — выгрузка расширения «Буфет» из конфигуратора.
Разделы инструкции «Состав подсистемы», «Карта файлов», «Что нужно доработать»
и «Структура объектов метаданных» построены по ней.

**Модули** (куда какой вставлять — см. раздел «Карта файлов» в инструкции):

| Файл | Место в конфигурации |
|---|---|
| `РасчетСебестоимостиМодуль.bsl` | Общий модуль `РасчетСебестоимостиМодуль` |
| `Справочник_Техкарточки_МодульОбъекта.bsl` | `Техкарточки` → Модуль **объекта** |
| `Справочник_Техкарточки_МодульФормы.bsl` | `Техкарточки` → Форма элемента |
| `Справочник_Техкарточки_МодульФормы_БезСправочникаЦен.bsl` | Та же форма — вариант без справочника цен |
| `Справочник_ЦеныНаИнгредиенты_МодульОбъекта.bsl` | `ЦеныНаИнгредиенты` → Модуль **объекта** |
| `Справочник_КулинарныеРецепты.bsl` | `КулинарныеРецепты` → Форма элемента |
| `Документ_ПриготовлениеБлюда_МодульОбъекта.bsl` | `ПриготовлениеБлюда` → Модуль объекта (проведение) |
| `Форма_ПриготовлениеБлюда.bsl` | `ПриготовлениеБлюда` → Форма документа |
| `РегистрСведений_ПриготовлениеПоРецептам.bsl` | `ПриготовлениеПоРецептам` → Модуль менеджера |
| `Обработка_ОбновлениеЦенВТехКарточках_МодульОбъекта.bsl` | `ОбновлениеЦенВТехКарточках` → Модуль объекта |
| `Обработка_ОбновлениеЦенВТехКарточках_МодульФормы.bsl` | Формы у обработки **нет** — создать, модуль вставить в неё |
| `Обработка_АнализСебестоимостиБлюд.bsl` | Обработки в расширении **нет** — создать, это её модуль объекта |
| `Обработка_АнализСебестоимостиБлюд_ФормаДетализации.bsl` | Модуль её формы `ДетализацияПоИнгредиентам` — расшифровка из отчёта |
| `Отчет_АнализСебестоимостиСДиаграммой.bsl` | Отчёта в расширении **нет** — создать, это модуль его формы |
| `Диагностика_ПодсистемыБуфет.bsl` | Внешняя обработка: проверка развёртывания |
| `ВнешняяОбработка_РегламентныеОперации.bsl` | Внешняя обработка: пересчёт по очереди и сверка по расписанию через механизм БСП |
| `Примеры_ТиповДиаграмм_1С.bsl` | Справочные примеры, не вставляется |
| `форма_отчета.bsl` | Сторонний образец формы отчёта (CC BY 4.0), не вставляется |

> У объекта может быть только один модуль формы: из пары
> «`МодульФормы` / `МодульФормы_БезСправочникаЦен`» выберите один файл.
>
> В выгрузке код справочников `Техкарточки` и `ЦеныНаИнгредиенты` лежит
> в модуле **менеджера**, где обработчики записи не вызываются. Перенос
> в модуль объекта — первый пункт раздела «Что нужно доработать».

## Боржники

Справочник учёта долгов с автозаполнением создателя, настройкой прав кассира
и кнопками подсчёта сумм по незакрытым долгам.

## Термінал

Патч БСП: ссылка на служебного пользователя OData хранится в справочнике `Константа`
вместо константы — это позволяет включить REST-сервис в базовых версиях конфигураций,
где добавлять константы нельзя.

**Модуль:** `OData_StdInterface_Settings_NoConst.bsl`

## Проверка кода

```
python проверить_код.py            # все папки
python проверить_код.py Буфет      # одна подсистема
```

Структурная проверка модулей без установленной платформы: парность блоков,
незакрытые области, вызовы общего модуля без экспортной функции, обращения
к базе внутри циклов. Код возврата `0` — замечаний нет.

Настоящий анализ синтаксиса — Конфигуратор либо BSL Language Server
(настройки в `.bsl-language-server.json`). Подробности — в разделе
«Проверка кода» инструкции по Буфету.

## Перед внедрением

Все инструкции предполагают изменение конфигурации через Конфигуратор.
**Делайте резервную копию информационной базы перед каждым этапом.**

Если в базе уже есть данные — начните с раздела «Обновление базы, в которой
уже есть данные» в [инструкции по Буфету](Буфет/ІНСТРУКЦІЯ.md).
