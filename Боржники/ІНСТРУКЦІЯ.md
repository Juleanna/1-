# 🗂️ Инструкция: справочник «Должники» в УТ 3.2 (конфигуратор) + подсчёт сумм

## Что делаем
- Создаём справочник «Должники» с нужными реквизитами и формами.
- Автозаполняем пользователя‑создателя.
- Настраиваем права для кассира.
- Добавляем кнопки для подсчёта сумм (по всем незакрытым, по имени) с диагностикой количества строк.

## Предпосылки
- УТ 3.2, доступ к Конфигуратору.
- Перед изменениями сделайте резервную копию ИБ.

## Шаги по созданию справочника
1) Открыть конфигурацию: «Конфигурация» → «Открыть конфигурацию».  
2) Добавить объект: «Справочники» → ПКМ → «Добавить». Имя: `Должники`, Синоним: «Должники». «Использование стандартных команд» — «Обычное».  
3) Реквизиты (в объекте → «Реквизиты» → «Добавить»):
   - `Контрагент` — Строка(150).
   - `СуммаДолга` — Число(15,2).
   - `ДатаВзятияДолга` — Дата.
   - `ДатаВозвратаДолга` — Дата.
   - `Комментарий` — Строка(200).
   - `СоздалПользователь` — Строка(100).
4) Формы:
   - Форма списка: автосоздать, добавить колонки Контрагент, СуммаДолга, ДатаВзятияДолга, ДатаВозвратаДолга, Комментарий, СоздалПользователь.
   - Форма элемента: автосоздать, `СоздалПользователь` сделать только для просмотра.
5) Автозаполнение создателя (модуль объекта справочника):
```1c
Процедура ПередЗаписью(Отказ)
    Если ЭтоНовый() Тогда
        СоздалПользователь = ИмяПользователя();
    КонецЕсли;
КонецПроцедуры
```
> ⚠ У справочника обработчик `ПередЗаписью` принимает **только** параметр `Отказ`.
> Вариант `ПередЗаписью(Отказ, РежимЗаписи, РежимПроведения)` — это сигнатура документа,
> в модуле справочника она не скомпилируется.
6) Команды/размещение: включить «ОткрытьСписок»; при необходимости добавить кнопку в раздел «НСИ и администрирование» или панель функций.  
7) Обновить конфигурацию базы: «Конфигурация» → «Проверить» → «Обновить конфигурацию базы данных» → запуск в пользовательском режиме.  

## Права для кассира
1) Конфигуратор → «Роли» → открыть роль кассира (или создать `Кассир_Должники`).  
2) В правах: «Справочники» → «Должники» → Чтение, Запись, Использование (Удаление — по необходимости).  
3) Обновить конфигурацию базы.  
4) В пользовательском режиме: «НСИ и администрирование» → «Настройка пользователей и прав» → пользователь «Кассир» → добавить роль. Перезапустить сеанс кассира.  

## Кнопки подсчёта — код с диагностикой (формы списка)
### Посчитать сумму всех незакрытых (кнопка формы)
```1c
&НаКлиенте
Процедура ПосчитатьСуммуВсех(Команда)
    Результат = ПосчитатьСуммуВсехСервер();
    Сообщить("Незакрытых строк: " + Формат(Результат.Количество, "ЧДЦ=0; ЧГ=0") +
             ", сумма: " + Формат(Результат.Сумма, "ЧДЦ=2"));
КонецПроцедуры

&НаСервереБезКонтекста
Функция ПосчитатьСуммуВсехСервер()

    // Пустая дата в запросе сравнивается с ДАТАВРЕМЯ(1, 1, 1) —
    // ЗначениеЗаполнено() в тексте запроса недоступно
    Запрос = Новый Запрос(
        "ВЫБРАТЬ
         |   КОЛИЧЕСТВО(*) КАК Количество,
         |   ЕСТЬNULL(СУММА(Д.СуммаДолга), 0) КАК Сумма
         |ИЗ
         |   Справочник.Должники КАК Д
         |ГДЕ
         |   Д.ДатаВозвратаДолга = ДАТАВРЕМЯ(1, 1, 1)
         |   И НЕ Д.ПометкаУдаления");

    Выборка = Запрос.Выполнить().Выбрать();
    Выборка.Следующий();

    Возврат Новый Структура("Количество, Сумма", Выборка.Количество, Выборка.Сумма);

КонецФункции
```

### Посчитать по имени (текущая строка), незакрытые
```1c
&НаКлиенте
Процедура ПосчитатьСуммуПоКонтрагенту(Команда)
    ТекСтрока = Элементы.Список.ТекущиеДанные;
    Если ТекСтрока = Неопределено Тогда
        Сообщить("Не выбрана строка в списке.");
        Возврат;
    КонецЕсли;

    Контрагент = ТекСтрока.Контрагент;
    Если ПустаяСтрока(Контрагент) Тогда
        Сообщить("В выбранной строке не заполнен контрагент.");
        Возврат;
    КонецЕсли;

    Результат = ПосчитатьСуммуПоКонтрагентуСервер(Контрагент);
    Сообщить("Незакрытых строк по '" + Контрагент + "': " + Формат(Результат.Количество, "ЧДЦ=0; ЧГ=0") +
             ", сумма: " + Формат(Результат.Сумма, "ЧДЦ=2"));
КонецПроцедуры

&НаСервереБезКонтекста
Функция ПосчитатьСуммуПоКонтрагентуСервер(Контрагент)

    Запрос = Новый Запрос(
        "ВЫБРАТЬ
         |   КОЛИЧЕСТВО(*) КАК Количество,
         |   ЕСТЬNULL(СУММА(Д.СуммаДолга), 0) КАК Сумма
         |ИЗ
         |   Справочник.Должники КАК Д
         |ГДЕ
         |   Д.Контрагент = &Контрагент
         |   И Д.ДатаВозвратаДолга = ДАТАВРЕМЯ(1, 1, 1)
         |   И НЕ Д.ПометкаУдаления");
    Запрос.УстановитьПараметр("Контрагент", Контрагент);

    Выборка = Запрос.Выполнить().Выбрать();
    Выборка.Следующий();

    Возврат Новый Структура("Количество, Сумма", Выборка.Количество, Выборка.Сумма);

КонецФункции
```

> ⚠ Отбор идёт по реквизиту `Контрагент`, а не по `Наименование`: имя должника хранится
> именно в реквизите. Если в вашей базе контрагент пишется в наименование элемента —
> замените `Д.Контрагент` на `Д.Наименование` в запросе и `ТекСтрока.Контрагент`
> на `ТекСтрока.Наименование` в клиентской процедуре.

### Привязка кнопок
- Кнопка «Посчитать сумму всех» → клиентская процедура `ПосчитатьСуммуВсех`.
- Кнопка «По контрагенту» → клиентская процедура `ПосчитатьСуммуПоКонтрагенту`.

Процедуры-обработчики команд формы объявляются **без** `Экспорт` — платформа
вызывает их по имени команды.

## Если результат пустой
- `Количество = 0` — значит у всех записей заполнена `ДатаВозвратаДолга` (долги закрыты)
  либо все записи помечены на удаление. Уберите из запроса строку
  `И Д.ДатаВозвратаДолга = ДАТАВРЕМЯ(1, 1, 1)` и проверьте, что записи вообще возвращаются.
- `Количество > 0`, а сумма 0 — не заполнен реквизит `СуммаДолга` в записях.
- Быстрая проверка: выполните тот же текст запроса в консоли запросов без условий раздела `ГДЕ`.

## Типовые ошибки, которых стоит избегать
| Ошибка | Почему неверно | Правильно |
|---|---|---|
| `ПередЗаписью(Отказ, РежимЗаписи, РежимПроведения)` в модуле справочника | Это сигнатура документа | `ПередЗаписью(Отказ)` |
| `Формат(Сумма, "ЧГ=15.2")` для двух знаков после запятой | `ЧГ` задаёт разделение разрядов, а не дробную часть | `Формат(Сумма, "ЧДЦ=2")` |
| `ЗначениеЗаполнено(...)` в тексте запроса | Функция недоступна в языке запросов | `Поле = ДАТАВРЕМЯ(1, 1, 1)` для пустой даты |
| Выборка всех строк справочника и фильтрация в цикле | Вся таблица тянется на сервер приложений | Отбор и агрегаты в разделах `ГДЕ` / `СУММА` |
| Забытый отбор `НЕ ПометкаУдаления` | В итог попадают помеченные на удаление записи | Добавить условие в `ГДЕ` |
